# Dataset

`SMSSpamCollection.tsv` - UCI SMS Spam Collection (5,574 English SMS messages).

Format: one message per line, `label<TAB>text`, label is `ham` or `spam`.

| label | count |
|---|---|
| ham | 4,827 |
| spam | 747 |

Source: https://archive.ics.uci.edu/dataset/228/sms+spam+collection (CC BY 4.0)

T. A. Almeida, J. M. G. Hidalgo, and A. Yamakami, "Contributions to the study of SMS spam filtering: new collection and results," Proc. 11th ACM Symposium on Document Engineering (DocEng), 2011, pp. 259-262.

The notebook downloads the dataset from UCI. This copy is kept here as a backup in case the UCI link is down.
